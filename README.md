# Car Rental Website

A simple full-stack Car Rental web application that allows users to browse available cars and book rentals through a clean and responsive interface. The project demonstrates basic CRUD (Create, Read, Update, Delete) operations using Node.js, Express, MongoDB, and a frontend built with HTML, CSS, and JavaScript.

## Features

- View available rental cars
- Book a car
- Create booking records
- View booking details
- Update booking information
- Delete bookings
- Responsive user interface
- MongoDB database integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/car-rental-app.git
```

2. Navigate to the backend folder

```bash
cd backend
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
npm start
```

5. Open your browser and visit

```
http://localhost:5000
```
